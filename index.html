Featured Project
01
LoRa-Based Fault-Tolerant Weather Monitoring System
A 'Dual-Brain' Wireless Sensor Network (WSN) using STM32 ARM Cortex-M3 and ESP32, communicating via 433 MHz LoRa over distances exceeding 1.2 km line-of-sight. Featuring the custom 'Survivor Protocol' for autonomous failover.
STM32 ESP32 LoRa SX1278 Python Flask MongoDB Vercel Embedded C++
Dual microcontroller architecture with STM32 as primary brain and ESP32 as failover node
Survivor Protocol: autonomously restores data flow within 15 seconds of gateway failure via GPIO interrupt
Integrated dust, gas, and atmospheric sensors with mathematical calibration models
Flask middleware API with sub-200ms ingestion to MongoDB Atlas, bypassing institutional firewalls
1.2 km LoRa range achieved in real-world line-of-sight deployment
